# Yaatal Commerce Backend

Rust/Loco backend for Yaatal commerce — products, orders, inventory, moments.

## Stack

- **Backend**: Rust + Loco framework
- **Database**: Postgres (PostGIS 17)
- **Search**: Qdrant + BGE-M3
- **Deployment**: Railway + Coolify

## Status

See the main [Yaatal Engine](https://github.com/Yaatal-labs/Yaatal) repo for the current backend.
This directory will contain Yaatal-Studio-specific commerce endpoints (content production, ad management, moment tracking).
