# Yaatal Prompts

Wolof and French prompt templates for content production.

## Structure

```
prompts/
├── tts/          # TTS prompts (voice direction, delivery instructions)
├── video/        # Video script generation prompts
├── detection/    # Market signal detection prompts
├── deconstruction/ # Content DNA extraction prompts
└── commerce/     # Product listing, ad copy prompts
```

## Language conventions

- **Wolof** — primary market language (Senegal, West Africa)
- **French** — secondary, for diaspora and francophone Africa
- **Code-switching** — many Senegalese users mix Wolof/French naturally; prompts should support this
