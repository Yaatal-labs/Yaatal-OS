# Yaatal NFC Delivery

Delivery confirmation for the Yaatal Engine — customer taps NFC on
delivery → Engine confirms delivery → closes order → releases payment.

## The role

This is NOT a product page or checkout. The Engine handles all commerce.
This module is solely the delivery confirmation bridge:

```
Merchant proposes:
  Packs order → includes NFC sticker with unique delivery code
  → ships package

Model executes:
  Customer receives package → taps NFC sticker with phone
  → opens https://yaatal.shop/d/{delivery_code}
  → sees "Colis reçu? Confirmez la livraison"
  → taps confirm button

Engine disposes:
  Receives confirmation → validates delivery code
  → marks order as delivered
  → releases payment to merchant (if escrowed)
  → triggers post-delivery flows (review request, re-order prompt)
  → invalidates the one-time-use delivery code
```

## NFC tag programming

Each NFC sticker is written with an NDEF URI record:
```
https://yaatal.shop/d/{delivery_code}
```

The `{delivery_code}` is a unique, one-time-use code generated by the
Engine when the order is shipped. It maps to a specific order + customer.

```python
from live.nfc_delivery import DeliveryBridge

bridge = DeliveryBridge(engine_base_url="https://yaatal.shop")

# Generate URL for one delivery
url = bridge.generate_delivery_url("DEL-ABC123XYZ")
print(url)  # https://yaatal.shop/d/DEL-ABC123XYZ

# Generate URLs for a batch of deliveries (before shipping)
urls = bridge.generate_delivery_urls(["DEL-001", "DEL-002", "DEL-003"])
# Write each URL to an NFC tag using an NFC writer app or nfcpy
```

## Standalone server (optional)

The Yaatal Engine can serve the `/d/{code}` page directly. This
standalone server is for testing or when the Engine isn't serving
the confirmation page yet.

```bash
pip install -r requirements.txt
uvicorn --factory live.nfc_delivery.server:app_factory --port 8000
```

## Routes

| Route | Description |
|---|---|
| `GET /d/{delivery_code}` | Mobile-first confirmation page (customer taps NFC) |
| `POST /api/delivery/confirm` | API: confirm delivery → Engine |
| `GET /api/delivery/{code}` | API: check delivery status |
