# Yaatal Integrations

External service integrations for Yaatal-Studio.

## Meta Ads MCP
Diaspora ad targeting (Paris, NYC, Dakar). Uses [mikusnuz/meta-ads-mcp](https://github.com/mikusnuz/meta-ads-mcp) (135 tools, Meta Marketing API v25.0).

## DSers MCP
Product sourcing from AliExpress, Alibaba, 1688, Accio. Uses [dsers/dsers-mcp-server](https://github.com/dsers/dsers-mcp-server) (official, hosted remote MCP, OAuth 2.1).

## Shopify MCP
E-commerce platform integration. Uses [GeLi2001/shopify-mcp](https://github.com/GeLi2001/shopify-mcp) (updated June 2026).
